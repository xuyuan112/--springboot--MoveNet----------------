### .cdm 文件格式要点（PowerDesigner 16.5 XML 版）
- 是 XML，CRLF 换行、无 BOM，含 `<?PowerDesigner ... Objects= Symbols= ...?>` 处理指令。
- **不要用 ElementTree 回写**：会丢处理指令、破坏格式。正确做法是**文本级正则手术**：读时 `open(..., newline='')` 保住 CRLF，删 `<o:EntityAttribute Id="oXX">...</o:EntityAttribute>` 整块。
- 结构：`<o:Entity>` → `<c:Attributes>` → `<o:EntityAttribute Id>`（本体只有 ObjectID/Mandatory，**真正的名称/代码/类型在 `<c:DataItem><o:DataItem Ref="oXX"/></c:DataItem>` 指向的模型级 DataItem 里**）。
- 标识符成员列表的集合名是 `<c:Identifier.Attributes>`（不是 `c:Attributes`），参考项是 `<o:EntityAttribute Ref="oXX"/>`。
- 删除属性后要顺带清理**不再被任何保留属性引用的 DataItem**（用集合差计算，避免误删共享 DataItem）。
- Diagram 里的 `EntitySymbol` / `RelationshipSymbol` 只引用实体/联系，不引用属性，无需同步。
