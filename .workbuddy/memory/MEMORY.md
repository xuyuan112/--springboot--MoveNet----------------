# 项目长期记忆

## 开题报告撰写要求与格式（源自《开题报告撰写说明.doc》，湖北理工学院/原黄石理工学院模板）

**内容（一）**：课题来源、研究目的意义、国内外研究现状和发展趋势综述、课题的主要研究内容及拟采取的技术路线和试验方案、研究基础、预期达到的目标及进度安排、阅读的主要文献资料等。

**字数（二）**：一般不少于 3000 字。

**打印格式（三）**
- 打印用纸：A4
- 页面设置：上 3.5cm；下 2.5cm；左 3.0cm；右 2.4cm；装订线 0.5cm；页眉 2.5cm；页脚 1.8cm；行间距：固定值 22 磅
- 字体字号：大标题 黑体三号；小标题 黑体四号；正文 宋体小四
- 页眉：“黄石理工学院开题报告”，宋体 5 号，居右；页码居页面底端靠右

**参考文献（四）**：按 GB7714-87 执行。书写顺序：序号·作者·论文名或著作名·杂志或会议名·卷号、期号或会议地点·出版社·页号·年。

## 技术备注（读取本地 Office 文件）
- 读本地 doc/docx 用 `tencent-local-office-edit`（editor_sdk）。
- `doc_resolve_document_structure` 的 `text_preview_length` 实际按**字节**截断、上限 200；长段落用 `doc_find.related_text`（±30 字）补齐，或直接用 `doc_get_table_info`（返回单元格完整 text）。
- `doc_to_image` 对含中文的 Windows 绝对路径报 file not found；改用结构/表格接口读文本更稳。
- 开题报告.docx 的**正文与参考文献全在表格 `table_id=e2jvnhxv` 的 R1C1 单元格内**，[1]~[n] 各条参考文献是**同一段落内用 `<w:br/>` 手动换行**分隔的（不是独立段落）。
- 在该单元格末尾追加条目：用 `doc_insert_paragraph_with_text`，`idx` 只能用**上一次返回的 `next_index`** 链式传递，手算/估算会把内容插到单元格外（错位后用 `doc_list_recent_ai_edits` + `doc_undo_ai_edit(target_version=...)` 撤销重做）。
- 新插入的段落不会继承原段落的直接格式：本文档正文段落有 `<w:spacing w:line="360" w:lineRule="auto"/>`（1.5 倍行距），需再调一次 `doc_modify_paragraph`（ranges + line_spacing=1.5 + line_spacing_rule=1）；字号/字体本身与 Normal 样式一致（宋体+Times New Roman、10.5pt）。
- 扫描版 PDF（无文本层）用 managed python + `pymupdf` 逐页 `get_text()`，题名页通常在 PDF 第 2~4 页。
